# orientale-ai-seminars
Seminari organizzati per il corso di laurea in Digital Humanities dell'Università L'Orientale

Sito pubblicato tramite GitHub Pages con l'archivio del **Seminario "AI e Multidisciplinarietà"**.

## Struttura

- `index.html` — homepage con l'elenco delle edizioni (dalla più recente)
- `cicli/2026.html` — Terzo Seminario "AI e Multidisciplinarietà" 2026 (dettagli TBA)
- `cicli/2025.html` — Secondo Seminario "AI e Multidisciplinarietà" 2025
- `cicli/2024.html` — Primo Seminario "AI e Multidisciplinarietà" 2024
- `assets/css/style.css` — stile condiviso
- `assets/img/` — immagini del sito

Per aggiungere un intervento, copiare il blocco `<article class="seminar-item">` commentato nella pagina dell'edizione corrispondente e compilarlo.
